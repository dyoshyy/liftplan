## Task 33: PWA

**Files:**
- `internal/presentation/httpapi/web/`（index.html / app.js / sw.js / app.webmanifest / icon.svg）
- `internal/presentation/httpapi/web.go`

**判断:**

- **サーバーに同居させる**。別ホスティングにすると CORS とトークンの扱いが増える。同一オリジンなら両方要らない。成果物が1つなので、画面と API のバージョンがずれない
- **静的資産だけを明示的に公開する**。「/api 以外は公開」にすると、後から足した経路が既定で公開になる。一覧を明示して fail-closed にする
- **記録は待ち行列に積んでから送る**。ジムの電波は途切れる。保存してから送れば、失敗しても消えない。IDはクライアントが採番するので、再送は安全（サーバーが冪等）
- **未来のメニューを手元に持たない**。表示は常にサーバーから取り直す。持つと、記録した結果が反映されているのか分からなくなる
- **API の応答をキャッシュしない**。古いメニューを出すくらいなら出ないほうがよい
