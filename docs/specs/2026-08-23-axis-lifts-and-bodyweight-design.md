## なぜ必要だったか

実際に使って、**「BIG3が軸」という前提が本人の実態と合っていない**ことが2回続けて出た。

1. **ルーマニアンデッドリフト**をハムの種目としてやっており、床引きデッドリフトはほぼやらない。RDL の重量が `床引きの1RM × 0.70` で出るので、床引きをやらなければ42日で古くなり**永久に「自分で決める」になる**
2. **背中の日の軸は懸垂。**自重（0kg）のセットは推定から除外されるので、**推定するものが何も残らない**

2つ目がこの節の出どころ。

## 自重は「体重 × 係数 + 加重」で扱う

```
負荷 = 体重 × 係数 + 加重
```

種目に `BodyweightFactor`（0.0〜1.0）を持たせる。0 は「自重が乗らない」。

| 種目 | 係数 |
|---|---|
| チンニング (`pull_up`) | 0.95 |
| ディップス (`dip`) | 0.93 |
| バックエクステンション (`back_extension`) | 0.55 |
| 上記以外 | 0 |

**係数は力学的な正確さを狙っていない。**推定1RMは伸びを測るための相対値なので、**時間を通じて一貫していれば足りる**。絶対値がずれても、同じ係数で測り続ける限り推移は正しく出る。

**記録は加重のまま。**`SetLog` に入るのは「プレートを何kg付けたか」。体重を足すのは推定するときだけ。こうしないと「あの日は何kg付けたか」が記録から読めなくなる。

**処方も加重で出す。**

```
表示する加重 = 目標負荷 − 体重 × 係数
```

画面には `+5kg` と出る。体重込みの `82.5kg` と言われても何をすればいいか分からない。差が0以下なら「自重」と出す。

**引いたあとの数字は刻みに乗らない。**丸めは総負荷に対してかかるので、体重を引くと `82.5 − 71.25 = 11.25kg` のような値が出る。**これは丸めない。**受け取った側が手元のプレートに合わせて調整する。丸め直すと総負荷が目標からずれ、どちらを信じる数字なのかが分からなくなる。

**体重の探し方は推定でも処方でも同じ規則にする。**対象日以前で最も新しい体重を使う。

**鮮度は見ない。**「42日より古い体重は使わない」は入れなかった。古い数字で計算され続ける経路は残るが、**推定1RM側の42日判定が先に効いて「自分で決める」になる**ので破綻しない。判定を二重に持つより、必要になってから足す。

処方だけ「当日の体重が必要」にすると、**毎日体重を測らない限り軸がほぼ毎日「自分で決める」になり**、この変更の目的そのものが消える。

体重が一つも記録されていない場合は既定値（70kg）で動く。**ただし、数週間ぶん記録したあとに体重を入れ始めると、それ以前の自重種目が推定から除外される**（D-120）。最初から入れておく必要がある。

**過去のデータが遡って推定に入る。**係数が入る前の0kgの自重セットは捨てられていた。その日の体重が記録されていれば推定できるので、推移グラフの過去に点が増える。
